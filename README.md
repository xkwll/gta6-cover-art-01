Offline web app that turns a photo and caption into GTA 6-style multi-panel cover art and exports it as a PNG in 1080x1080, 1080x1350 or 1920x1080.

## Run it

```sh
python3 -m http.server in app dir / open app/index.html, and MAKEFUN_OUTPUT_DIR=out node main.ts
```
